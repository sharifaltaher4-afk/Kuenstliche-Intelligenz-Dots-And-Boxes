# Aufgabe P23 – Vorhersagen mit PyTorch

## Testen der trainierten Modelle

Nach dem Training wurden die drei Modelle NN1, NN2 und NN3 auf dem Fashion-MNIST-Testdatensatz evaluiert.

### Ergebnisse

| Modell | Test Loss | Test Accuracy |
| ------ | --------- | ------------- |
| NN1    | 0.4656    | 83.98 %       |
| NN2    | 0.3684    | 86.88 %       |
| NN3    | 0.7679    | 68.51 %       |

### Beobachtungen

#### NN1 (ohne Hidden Layer)

* Erreicht eine Accuracy von 83.98 %.
* Lernt die grundlegenden Muster des Datensatzes.
* Konvergiert schnell.
* Aufgrund der fehlenden Hidden Layer können nur einfache Zusammenhänge gelernt werden.

#### NN2 (2 Hidden Layer)

* Erreicht mit 86.88 % die höchste Accuracy.
* Besitzt den niedrigsten Test Loss.
* Zeigt einen stabilen Trainingsverlauf.
* Die zusätzlichen Hidden Layer ermöglichen das Lernen komplexerer Merkmale.

#### NN3 (tiefes Netzwerk)

* Erreicht nur 68.51 % Accuracy.
* Höchster Test Loss.
* Lernt deutlich langsamer als NN1 und NN2.
* Die vielen Schichten und die sehr kleinen Hidden Layer (4 Neuronen) erschweren das Lernen.

## Beispielvorhersage

Für ein ausgewähltes Testbild wurde folgende Vorhersage getroffen:

| Modell | Echtes Label | Vorhersage |
| ------ | ------------ | ---------- |
| NN1    | 9            | 9          |
| NN2    | 9            | 9          |
| NN3    | 9            | 9          |

Alle drei Modelle klassifizieren dieses Beispiel korrekt.

### Konfidenz der Modelle

NN1:

```text
Klasse 9: 67.99 %
```

NN2:

```text
Klasse 9: 94.16 %
```

NN3:

```text
Klasse 9: 39.79 %
```

NN2 trifft die Vorhersage mit der höchsten Sicherheit. NN3 sagt zwar die richtige Klasse voraus, verteilt die Wahrscheinlichkeit jedoch auf mehrere Klassen und ist daher deutlich unsicherer.

---

# Einfluss der Dropout-Rate

Für NN2 wurden verschiedene Dropout-Raten untersucht.

## Ergebnisse

| Dropout | Test Loss | Test Accuracy |
| ------- | --------- | ------------- |
| 0.0     | 0.3648    | 86.78 %       |
| 0.2     | 0.3684    | 86.88 %       |
| 0.5     | 0.3852    | 86.27 %       |

## Beobachtungen

### Dropout = 0.0

* Höchste Lernkapazität.
* Sehr gute Accuracy.
* Keine Regularisierung.
* Gefahr von Overfitting bei längerer Trainingszeit.

### Dropout = 0.2

* Beste Accuracy im Experiment.
* Gute Balance zwischen Lernen und Generalisierung.
* Stabiler Trainingsverlauf.

### Dropout = 0.5

* Niedrigste Accuracy.
* Höherer Test Loss.
* Training verläuft langsamer.
* Zu viele Neuronen werden deaktiviert.

---

# Einschätzung zu Overfitting und Underfitting

Während der fünf Trainingsepochen konnte kein starkes Overfitting beobachtet werden. Die Ergebnisse von Dropout 0.0 und 0.2 unterscheiden sich nur geringfügig.

Bei einer hohen Dropout-Rate von 0.5 zeigt sich eine leichte Tendenz zum Underfitting, da das Netzwerk weniger effektiv lernen kann.

---

# Bevorzugte Architektur

Für diese Aufgabe wird NN2 mit einer Dropout-Rate von 0.2 bevorzugt.

Begründung:

* Höchste Test-Accuracy (86.88 %)
* Stabiler Trainingsverlauf
* Gute Generalisierung
* Moderate Modellkomplexität
* Bessere Ergebnisse als NN1 und NN3

NN2 mit Dropout 0.2 stellt somit den besten Kompromiss zwischen Genauigkeit, Stabilität und Generalisierungsfähigkeit dar.
